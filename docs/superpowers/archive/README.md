# Archive — plans and specs written before Spec Kit

Nine documents that guided real work: the live-lesson module, the QA system,
the lesson Q&A widget, the full exercise-type player. Everything described in
them has shipped.

They are kept because they explain *why* parts of the product are shaped the
way they are, and that reasoning is not recoverable from the code. They are
**not** updated, and nothing new is added here.

From 2026-08-16 all planning goes through Spec Kit instead:

- Specifications live in `specs/NNN-short-name/` at the repository root.
- Principles live in `.specify/memory/constitution.md`.
- The workflow is described in the root `CLAUDE.md`.

Two planning systems drift apart within a month, and then nobody knows which
one is true. That is the only reason these moved rather than staying where they
were.
