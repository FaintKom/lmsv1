# Implementation Plan: дизайн-система v2 «Цветные поля»

**Branch**: `feat/design-system-v2` | **Date**: 2026-09-30 | **Spec**: [spec.md](spec.md)

## Summary

Палитра v2.2.0 остаётся. Меняются шрифты (Geologica + Onest), скругления,
тени, форма компонентов, цвет предмета как поверхность, движение. Опора на то,
что в проекте уже есть: все значения живут в `:root` и `.dark` внутри
`globals.css` и проходят в Tailwind через `@theme inline`. Смена значения
токена перекрашивает все экраны, которые им пользуются. Ручная работа нужна
там, где стоит мимо токена: 493 hex, 110 классов сырой палитры, 24 градиента,
33 файла с моноширинными заглавными подписями, 49 мест с `btn-pop` и `text-[10/11px]`.

Работа идёт шестью PR. Первым идёт храповик: проверка в CI, после которой
нарушений не может стать больше. Дальше фундамент, потом экраны группами.

## Technical Context

**Language/Version**: TypeScript 5 strict, React 19, Next.js 16 App Router
**Primary Dependencies**: Tailwind 4 (`@theme inline`), Motion (уже стоит). Новых зависимостей нет.
**Storage**: нет. Бэкенд не меняется: предмет курса выводится из `courses.category` на фронте.
**Testing**: Vitest (храповик дизайна, по образцу `no-hardcoded-strings.test.ts`), Playwright (`e2e/motion.spec.ts`, `e2e/dark-theme.spec.ts`, журналы в `e2e/journeys`)
**Target Platform**: браузеры, 390–1440px, светлая и тёмная тема (`.dark` на `<html>`)
**Performance Goals**: движение только `transform`/`opacity`; вес сборки растёт не больше чем на два woff2-шрифта (~120 КБ)
**Constraints**: шрифты самохостятся (сбой 2026-08-11 с Google Fonts при сборке); шесть локалей на каждую новую строку; сборка идёт в CI, прод только тянет образ
**Scale/Scope**: 85 экранов, 293 компонента

## Порядок работ (PR)

Мёрж строго по одному: каждый мёрж — это деплой (CLAUDE.md).

1. **Храповик.** `design-system.test.ts` считает нарушения по файлам и сверяет
   с `design-baseline.json`. Новый файл не может принести нарушение, старый не
   может их прибавить. Правила перечислены в [contracts/tokens.md](contracts/tokens.md)
   и [contracts/motion.md](contracts/motion.md). Визуально ничего не меняется.
2. **Фундамент.** Шрифты, радиусы, тени, токены предметов, новые утилиты
   движения, `components/ui`. Убираются `btn-pop` и маркер `<em>` на заголовках.
   Все 85 экранов меняются сразу, поэтому к PR прикладываются снимки «до/после»
   всех экранов. `e2e/mobile-audit.mjs` уже обходит все маршруты по ролям, но
   только проверяет их на 390px; ему добавляется флаг `--shots`, который
   сохраняет снимок каждого маршрута на 390 и 1440.
3. **Экраны ученика.** Главная, каталог, урок, прогресс, достижения, календарь,
   задания. Здесь появляются приёмы движения M2, M4, M5, M9.
4. **Экраны преподавателя и методиста.** Конструктор курса и урока, журнал,
   библиотека, проверка работ. M6, M7, M8.
5. **Админка, вход, публичные страницы.** `/admin/*`, `(auth)`, лендинг, `/pricing`,
   `/demo`, юридические страницы, печатные формы.
6. **Ноль.** Базовая линия храповика сводится к нулю для всего, кроме явных
   исключений (цвета данных в графиках, воксельная комната, контент уроков).
