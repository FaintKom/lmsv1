# Quickstart: проверка дизайн-системы v2

## Храповик

```bash
cd frontend && npx vitest run src/lib/design
```

Ждём: зелёный. Позитивный контроль: вписать `className="bg-[#ff0000]"` в любой
компонент, тест должен упасть и назвать файл и правило `raw-hex`. Потом убрать.

## Движение

```bash
cd frontend && npx playwright test e2e/motion.spec.ts
```

Ждём: каждый приём M2–M10 проходит дважды, с обычным движением и с
`reducedMotion: 'reduce'`. Нужен поднятый QA-стек (`docs/TESTING.md`).

## Глазами

1. Поднять QA-стек, войти демо-учеником.
2. Главная: плитки курсов в цветах предметов, блоки появляются по очереди.
3. Урок: неверный ответ вздрагивает и показывает подсказку, верный даёт
   галочку и «+10 XP».
4. Переключить тему: всё читается, белого текста на жёлтом нет нигде.
5. Сузить окно до 390px: меню внизу, ничего не обрезано (проверки specs/065–067).

## Снимки для PR

```bash
cd frontend && node e2e/mobile-audit.mjs --shots
```

Флаг `--shots` появляется в PR 2. Скрипт обходит все маршруты по ролям и
сохраняет снимки на 390 и 1440. Снимки «до» снимаются с `main`,
«после» с ветки.
