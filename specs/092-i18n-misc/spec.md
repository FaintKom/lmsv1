# 092 — последние мелкие экраны на шести языках

**Ветка**: `fix/i18n-misc` · **Создано**: 2026-10-08

## Что не так

Десять файлов из allowlist говорили по-английски на любом языке интерфейса:
- панель JSON-конфига упражнения в библиотеке;
- печатная версия курса;
- упражнения categorize, matching и ordering у ученика: кнопка «Submit
  Answer», подсказки при перетаскивании, aria-label кнопок;
- переключатель организации;
- общий диалог подтверждения, которым пользуются все экраны;
- видеоплеер, YouTube-встройка, iframe интерактивного виджета.

## Что меняется

- 26 ключей `ui.*` в шести языках. Где строка уже была, взяты готовые ключи:
  `common.close`, `common.cancel`, `common.confirm`, `exercise.loading`,
  `exercise.answerLabel`.
- У кнопок «Отформатировать» и «Копировать» в JSON-панели был только
  `title`, теперь есть и `aria-label`.
- aria-label с подстановкой («Поднять „{item}“») собираются через `replace`.
- Подписи, которые экран передаёт в диалог подтверждения сам, остаются за
  ним: перевод касается только значений по умолчанию.
- 10 файлов убраны из allowlist.

Юридические страницы не тронуты.

## Проверка

- `tsc --noEmit` проходит без ошибок, Vitest — 78 файлов, 691 тест.
- Детектор английских строк по десяти файлам пуст.
- `grep -rni` по e2e: старые подписи нигде не встречаются.
