# Quickstart: проверка

## Тесты бэкенда

Нужен настоящий PostgreSQL: `docker compose up -d db` (образ
`pgvector/pgvector:pg16`).

```bash
cd backend && python -m pytest tests/test_auth.py -k menu_visibility -v
```

Ожидание: три теста зелёные.

**Демонстрация по принципу II.** Тот же прогон на коде до правки — первый тест
(положительный контроль) падает: в `org_branding` нет ключа `menu_visibility`.
Проверяется откатом одной строки в `backend/app/auth/router.py`.

## Проверка в браузере

Стенд QA поднимается как обычно (см. корневой `CLAUDE.md`); во втором чате —
со своим `.env.qa.local`.

1. Войти администратором, открыть `/admin/settings`, снять галочку у «Оценки»,
   сохранить.
2. **US3**: пункт «Оценки» исчезает из бокового меню сразу, до перезагрузки.
3. Выйти, войти преподавателем той же школы.
4. **US1**: пункта «Оценки» в меню нет.
5. **SC-003**: на вкладке сети нет запроса к `/admin/organizations/…` —
   ни 200, ни 403. Карта приехала внутри `/auth/me`.
6. Вернуть галочку, сохранить, обновить страницу преподавателя — пункт
   на месте.

## Проверка изоляции руками (необязательно, тест это уже закрывает)

Ответ `/auth/me` у преподавателя второй школы содержит `menu_visibility`
своей школы. Подставить чужую организацию в запрос нельзя: параметра нет,
организация берётся из токена.

## Гейты перед слиянием

```bash
cd backend && ruff check . && python -m pytest
```

```bash
cd frontend && npm run lint && npx tsc --noEmit && npm test
```

Фронтенд трогает два файла и не добавляет ни строк с текстом, ни новых
`.tsx` — ратчет i18n и проверка шести локалей к этой правке безразличны.
