# 070 — Названия типов упражнений на языке интерфейса

## Проблема

Учитель с русским интерфейсом видит в конструкторе урока, библиотеке и списках
работ английские названия: Quiz, Matching, Fill Blanks. Названия зашиты
строками в `frontend/src/lib/api/exercises.ts` (`EXERCISE_TYPE_LABELS` и
`label` в `EXERCISE_TYPES_META`), перевода для них нет ни в одном языке. Группы
над ними («Базовые», «Языки») при этом переведены — строка выглядит сломанной.

Новое упражнение получает заголовок `New Quiz` — по-английски, и этот заголовок
сохраняется и виден ученику.

## Что нужно

- 27 типов упражнений называются на языке интерфейса во всех шести локалях:
  в выборе типа, фильтре и таблице библиотеки, карточке упражнения, списке работ,
  редакторе урока и курса.
- Заголовок нового упражнения по умолчанию — название типа на языке учителя.
- Источник названий один: ключ `exerciseTypes.<тип>` в словарях. Английских
  строк-названий в коде не остаётся, так что новый тип без перевода не соберётся
  или упадёт в тесте парности.

## Вне рамок

- Переименование уже созданных упражнений с заголовком `New …`.
- Названия типов в бэкенде и выгрузках.

## Проверка

- Vitest: для каждого типа из `EXERCISE_TYPES_META` в каждой локали есть ключ
  `exerciseTypes.<тип>`, и в `ru` он не совпадает с английским (кроме
  «SCORM / xAPI»).
- Браузер: библиотека и выбор типа в редакторе урока на русском.
