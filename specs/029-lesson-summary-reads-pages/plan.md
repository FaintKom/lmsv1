# Implementation Plan: Список уроков перестаёт врать, что они пусты

**Branch**: `fix/course-editor-lesson-summary` | **Date**: 2026-08-20 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/029-lesson-summary-reads-pages/spec.md`

## Summary

`getContentSummary` в редакторе курса не знает формата страниц и печатает
«No content yet» под каждым уроком. Решение читает страницы, считает блоки по
видам и отдаёт строку вида `Pages: 2 · Text: 3, Exercise: 5`. Решение о том,
что показать, выносится в чистую функцию рядом со страницей — её и проверяют
тесты; компонент только подставляет переводы.

Только фронтенд. Ни схемы, ни бэкенда, ни миграции.

## Technical Context

**Language/Version**: TypeScript 5 strict, React 19, Next.js 16

**Primary Dependencies**: собственный `useTranslation` поверх словарей локалей

**Storage**: не затрагивается — читается `lesson.content`, уже пришедшее с сервера

**Testing**: Vitest, тест рядом с модулем

**Target Platform**: браузер

**Project Type**: web (фронтенд монорепо)

**Constraints**: файл `admin/lessons/[lessonId]/edit/page.tsx` правят два

его **не трогает**, она в `admin/courses/[courseId]/edit/page.tsx`

**Scale/Scope**: 66 уроков в проде, до нескольких сотен блоков в уроке

## Форма сводки

`Pages: 2 · Text: 3, Exercise: 5` — и без части `Pages`, когда страница одна.

Числа стоят **после** подписи, а не перед ней. Это не украшение: у русского
три формы множественного числа, и «3 блока / 5 блоков / 1 блок» потребовало бы
правил склонения в шести локалях. «Блоков: 3» верно при любом числе.

Ключи, по восемь на локаль: `summaryEmpty`, `summaryPages`, `kindText`,
`kindHtml`, `kindVideo`, `kindPresentation`, `kindExercise`, `kindAssignment`.

## Порядок работ

1. Красные тесты на `lessonSummary` — прогнать, увидеть падение.
2. `lesson-summary.ts`: разбор страниц, подсчёт по видам, порядок видов
   фиксированный (как в меню добавления), пустые виды не показываются.
3. Ключи в шесть локалей.
4. Замена `getContentSummary` в `page.tsx` на вызов плюс перевод.
5. Удаление веток v1 и v2 из старой функции — они мертвы после миграции.
6. `npm test`, `tsc --noEmit`.
7. Браузер: редактор курса Kitchen Sink, где сегодня «No content yet» у всех.
8. PR, CI, мерж, деплой, проверка в проде.
