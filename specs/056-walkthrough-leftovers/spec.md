# Три мелочи прогона: код в домашке, кракозябры в выгрузке, кнопка-ловушка

**Дата**: 2026-08-23 · **Ветка**: `fix/walkthrough-leftovers` · **Статус**: разобрано

Три независимые находки ручного прогона 2026-08-23, каждая слишком мелкая для
своей спеки и слишком заметная, чтобы остаться. Общего между ними только то, что
все три попались за один проход.

## Н-18. Домашку по программированию нельзя приложить файлом

Задание говорит «пришлите код», ученик прикладывает `hello.py` и читает:

```
File type .py is not allowed.
Allowed: .doc, .docx, .gif, .jpeg, .jpg, .pdf, .png, .ppt, .pptx, .svg, .webp, .xlsx, .zip
```

Ни исходников, ни даже `.txt`. Список собран из картинок, офисных документов и
архива — из всего, кроме того, что производит курс программирования.

Добавлены текстовые и исходные расширения: `.txt`, `.md`, `.csv`, `.json`,
`.py`, `.js`, `.ts`, `.html`, `.css`, `.java`, `.c`, `.cpp`, `.cs`, `.go`,
`.rb`, `.sql`. Сигнатур у них нет и быть не может — безопасность здесь в другом:
файл сохраняется, никогда не исполняется и отдаётся вложением.

Проверка при этом не ослабла: `.exe` по-прежнему отклоняется, имя файла
по-прежнему заменяется на UUID, весь набор P0 по загрузкам проходит.

**Отдельно, не в этой правке.** В списке разрешённых есть `.svg` — формат
исполняемый, и его текст проверяется регуляркой. Это стоит разобрать отдельно:
вопрос там не «добавить», а «оставлять ли».

## Н-23. Выгрузка оценок открывается кракозябрами

`GET /admin/gradebook/export` отдаёт корректный UTF-8 без метки в начале файла.
Excel под Windows читает такой файл в системной кодировке, и школа видит вместо
имён и названий заданий мусор. Лечится тремя байтами: файл теперь начинается с
метки UTF-8.

XLSX-выгрузка этим не болеет — там кодировка внутри формата.

## Н-01. Кнопка «отключить школу» носила иконку «люди» и не спрашивала

В строке школы три кнопки: карандаш, «люди» и корзина. Средняя, вопреки иконке,
отключает школу — и делала это молча, тогда как удаление рядом всегда
спрашивало подтверждение. Промах мимо корзины гасил школу без единого вопроса.

Иконка стала `Power`, а действие спрашивает подтверждение с ясной ценой: войти
не сможет никто, пока школу не включат обратно. Обратное включение
подтверждения не требует — оно ничего не ломает.
