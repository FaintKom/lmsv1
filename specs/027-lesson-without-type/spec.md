# Feature Specification: A Lesson Has No Type

**Feature Branch**: `feat/lesson-without-type`
**Created**: 2026-08-20
**Status**: Draft
**Input**: «урок должен быть уроком без типа, а внутри блоки с типами» (2026-08-19) и «Нужно оставить только новую и без старых данных и схем, все новое» (2026-08-20).

## Что осталось от старого

Этап 2 сделал урок контейнером блоков, но **создание урока по-прежнему
начинается с выбора типа**: Text · Video · Quiz · Code · File Upload ·
Interactive · Theory. Выбор ведёт в отдельный конструктор (quiz-builder,
challenge-builder, file-upload-config, interactive-builder, theory) и в
отдельный ученический рендер `LegacyContent` с `QuizTaker`,
`InteractiveTaker`, `FileUploader`.

Каждый из этих типов **уже существует как тип упражнения**: quiz, code
challenge, file upload, matching / ordering / fill blanks / true-false /
categorize, презентация. То есть это ровно то дублирование, которое
владелец просил убрать, — только на уровне урока.

В проде уроков, которым нужен старый рендер, нет: все 65 лежат в
страницах (проверено запросом). Держат старый путь только:
- форма создания урока с семью типами;
- пять конструкторов в редакторе курса;
- `LegacyContent` и три «такера» в плеере ученика;
- сквозной тест `all-content-types.spec.ts`, который создаёт уроки всех
  семи типов через API.

## User Scenarios & Testing

### User Story 1 — Урок создаётся без выбора типа (P1)

Учитель жмёт «Добавить урок», вводит название — и получает урок-контейнер
со страницей. Тип не спрашивают, потому что типы живут внутри, у блоков.

**Acceptance**:
1. **Given** форму создания урока, **Then** в ней нет выбора типа.
2. **Given** созданный урок, **When** учитель его открывает, **Then**
   это редактор страниц с кнопками «добавить контент» и «добавить
   страницу».

### User Story 2 — Старые конструкторы удалены (P1)

В редакторе курса не остаётся отдельных конструкторов quiz / code /
file upload / interactive / theory: всё это добавляется блоком внутри
урока.

**Acceptance**:
1. **Given** редактор курса, **Then** ни один урок не открывает
   отдельный конструктор.
2. **Given** сборку, **Then** файлы `quiz-builder`, `challenge-builder`,
   `file-upload-config`, `interactive-builder` и ветки `LegacyContent`
   удалены, и ничто на них не ссылается.

### User Story 3 — Ученик читает уроки одинаково (P1)

Плеер ученика знает один путь: страницы с блоками. `LegacyContent`,
`QuizTaker`, `InteractiveTaker`, `FileUploader` и пять компонентов в
`components/submissions/exercises/` удаляются.

**Acceptance**:
1. **Given** любой урок в проде, **Then** он открывается как страницы.
2. **Given** урок, чей контент почему-то не страницы, **Then** ученик
   видит честное «в уроке пока нет содержимого», а не пустой экран.

### User Story 4 — Сквозной тест проверяет то, что осталось (P1)

`all-content-types.spec.ts` перестаёт создавать уроки семи типов и
начинает создавать один урок со страницами, где каждый тип — блок.
Покрытие типов не сокращается.

**Acceptance**:
1. **Given** гейт E2E, **Then** он проходит все прежние типы через
   блоки урока.

### Edge Cases

- `content_type` в БД остаётся (колонка не удаляется) — но перестаёт
  что-либо решать; новые уроки пишут `text`.
- Урок с легаси-конфигом, если такой найдётся в чужой базе: миграция
  этапа 9 его не трогала, плеер покажет честную заглушку.

## Requirements

- **FR-001**: Создание урока не спрашивает тип.
- **FR-002**: Конструкторы уроков-типов удалены из редактора курса.
- **FR-003**: `LegacyContent` и три «такера» удалены из плеера.
- **FR-004**: Покрытие E2E по типам сохраняется, но идёт через блоки.
- **FR-005**: Ни один существующий урок не ломается: все они уже
  страницы.

## Success Criteria

- **SC-001**: Ни одного файла, который рисует урок в обход страниц.
- **SC-002**: Форма создания урока — одно поле «название».
- **SC-003**: E2E проходит тот же список типов, что и раньше.

## Assumptions

- Колонку `content_type` не трогаем: она ничего не стоит и её удаление —
  отдельная миграция без пользы для владельца.
- Тип «theory» (слайды) закрыт блоком «презентация» из этапа 7.
