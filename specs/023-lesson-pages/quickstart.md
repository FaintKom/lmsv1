# Quickstart: Lesson Pages

## Prerequisites

Dev-стек: postgres `lms29-db-1`, uvicorn :8000 (перезапустить после
правки тьютора), `npm run dev` :3000, sandbox для exercise-превью.

## Validation scenarios

1. **Видимость (US1)**: открыть пустой урок в редакторе — «+ Add
   content» и «+ Add page» видны без наведения; добавить текст и
   задание в страницу 1.
2. **Страницы (US2)**: добавить страницу 2 (видео + 2 задания);
   поменять страницы местами; удалить пустую страницу без
   подтверждения, непустую — с подтверждением.
3. **Ученик (US3)**: открыть урок студентом — страница 1 и «1 / 2»;
   элементы страницы 2 отсутствуют в DOM; Next → страница 2, скролл
   вверху; на последней — переход к следующему уроку; перезагрузка на
   ?page=2 возвращает страницу 2.
4. **Грандфазер (US4)**: QA Lesson (231 v2-блок) — ученик видит прежнюю
   ленту без пагинации; редактор показывает одну страницу.
5. **Презентация (US5)**: блок presentation с Google Slides embed-URL —
   рамка в редакторе и у ученика; кривой URL — заглушка.
6. **Тьютор**: на v3-уроке ask-виджет получает текст урока (pytest
   RED→GREEN + ручной вопрос).
