## Что вскрылось по ходу

- Локальная база под pytest не получает новых значений enum: `create_all`
  строит тип только когда его нет. В `conftest.py` добавлен тот же
  `ADD VALUE IF NOT EXISTS`, что и в миграции.
- `test_qa_fixtures.py` требует `*Config`-модель на каждый тип — заведена
  `ListeningConfig`, она же служит письменным описанием настройки.
- `test_submissions.py` требует образец конфигурации на каждый watched-тип.
- Первая версия счётчика прослушиваний считала по времени и списывала второе
  прослушивание тому, кто нажал паузу в первые полсекунды. Видно это стало
  только в браузере; тесты бы промолчали.
