# Feature Specification: Редактор урока говорит на языке учителя

**Feature Branch**: `fix/lesson-editor-i18n`
**Created**: 2026-08-20
**Status**: Draft
**Input**: «в редакторе урока показывается захардкоженная английская строка вместо перевода» (2026-08-20)

## Что происходит сейчас

Учитель ставит на страницу урока блок-задание. Задание ещё не выбрано,
и блок предлагает выбрать тип. Заголовок этого предложения написан
по-английски прямо в коде:

```tsx
<p className="mb-3 text-xs font-semibold uppercase tracking-wider text-primary">
  Pick exercise type — created instantly
</p>
```

`frontend/src/app/(admin)/admin/lessons/[lessonId]/edit/page.tsx:1000`

Ключ `admin.lessonEditor.pickExerciseType` **уже лежит во всех шести
словарях**, переведённый. Его просто никто не вызвал. Турецкий учитель
видит английскую строку, хотя перевод для неё написан и загружен.

Строка не одна. В том же файле ещё пятнадцать литералов: подписи кнопок
добавления блока, индикатор сохранения, подсказки пустых блоков,
всплывающие подписи ручки перетаскивания и корзины. У тринадцати из них
ключи тоже уже есть. Трёх ключей нет — «Slides», «Assignment» и
«Loading editor…».

## Почему это прошло мимо проверки

Шлюз `no-hardcoded-strings.test.ts` смотрит на файл целиком: есть ли в нём
подстрока `useTranslation`. Есть — файл считается переведённым. Внутрь
теста не заглядывает намеренно, разбор синтаксиса дал бы слишком много
ложных срабатываний.

Значит шлюз ловит ровно один случай: новый файл, где i18n не подключили
вообще. Файл редактора подключил `useTranslation` и переводит почти всё,
поэтому шестнадцать литералов внутри него для теста невидимы.

Это не повод чинить шлюз в этом PR. Разбор синтаксиса — отдельная работа
с отдельной ценой, и её надо мерить на всех 140 переведённых файлах, а не
на одном.

## User Scenarios & Testing

### User Story 1 — Выбор типа задания читается на своём языке (P1)

Учитель с турецким интерфейсом добавляет блок-задание. Заголовок над
сеткой типов читается по-турецки, как и названия групп под ним, которые
уже переводятся.

**Проверка**: строка идёт через `t("admin.lessonEditor.pickExerciseType")`,
ключ есть в en, es, ru, tr, de, uk.

### User Story 2 — Остальной редактор не сбивается на английский (P2)

Тот же учитель добавляет блоки, сохраняет урок, наводит курсор на ручку
перетаскивания. Подписи кнопок, индикатор сохранения и всплывающие
подсказки — на его языке.

**Проверка**: в файле не остаётся английских литералов в тексте для
человека.

## Границы

**Входит:** только
`frontend/src/app/(admin)/admin/lessons/[lessonId]/edit/page.tsx`
и шесть словарей.

**Не входит:** соседние файлы редактора, шлюз `no-hardcoded-strings`,
чистка остальных 140 файлов. Образцы в полях ввода
(`<div>Raw HTML…</div>`, адреса YouTube и Google Slides) остаются как
есть: это примеры разметки и адресов, а не текст для чтения.

## Критерий готовности

- `npm test` зелёный, включая `translations.test.ts` (совпадение ключей
  во всех шести словарях) и `no-hardcoded-strings.test.ts`.
- `npx tsc --noEmit` без ошибок.
- Ни один ключ не добавлен в `i18n-allowlist.ts` — список только
  сокращается.
