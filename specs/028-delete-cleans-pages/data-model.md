# Data Model: Удаление задания убирает за собой

Схема не меняется. Миграции нет. Меняется только содержимое колонки
`lessons.content` — и только у тех уроков, которые ссылались на удалённое.

## Что лежит в `lessons.content`

Колонка `JSONB`, форма одна (`version: 3`), обеспечена миграцией
`p4g3sv3rs10n`:

```jsonc
{
  "version": 3,
  "pages": [
    {
      "id": "page_1",
      "title": "Разминка",          // необязателен
      "blocks": [
        { "id": "b1", "type": "text",     "sort_order": 0, "page": 1,
          "body": "<p>Текст.</p>" },
        { "id": "b2", "type": "exercise", "sort_order": 1, "page": 1,
          "exercise_id": "00000000-0000-0000-0000-000000000001" },
        { "id": "b3", "type": "assignment", "sort_order": 2, "page": 1,
          "assignment_id": "00000000-0000-0000-0000-000000000002" }
      ]
    }
  ]
}
```

`sort_order` и `page` — производные: первое от позиции блока в списке,
второе от индекса страницы. Их не редактируют, их пересобирают.

## Что делает уборка

Вход: вид блока (`exercise` или `assignment`), имя поля со ссылкой
(`exercise_id` / `assignment_id`), номер удаляемого объекта.

1. Из каждой страницы выбрасываются блоки, у которых `type` совпал с видом,
   а поле со ссылкой равно номеру.
2. Оставшимся блокам страницы `sort_order` присваивается заново, с нуля.
3. Всем блокам страницы `page` присваивается заново, по индексу страницы.
4. Страницы остаются все, включая опустевшие; `id` и `title` сохраняются.
5. Если ни один блок не выброшен, урок не переписывается вовсе.

### Пример

До удаления `…0001` (страница из трёх блоков):

| id | type | sort_order | page |
|---|---|---|---|
| b1 | text | 0 | 1 |
| b2 | exercise → …0001 | 1 | 1 |
| b3 | text | 2 | 1 |

После:

| id | type | sort_order | page |
|---|---|---|---|
| b1 | text | 0 | 1 |
| b3 | text | 1 | 1 |

Номер `1` не остаётся пустым: `b3` занимает освободившееся место.

## Границы

- **Организация.** Уроки берутся только те, чей курс принадлежит той же
  организации, что и удаляемое задание.
- **Контент не-страницы.** Если `content` не имеет вида
  `{version: 3, pages: [...]}` — пустой словарь, `null`, что-то
  неожиданное, — урок остаётся как есть, без ошибки. Таких уроков в проде
  нет, но удаление не должно падать из-за формы чужих данных.
- **Решения учеников.** `exercise_submissions` эта уборка не трогает.
  Удаление задания, у которого есть решения, ведёт себя как сегодня.

## Сущности

| Сущность | Роль здесь |
|---|---|
| `Exercise` | удаляемое; несёт `org_id`, по которому ограничивается выборка |
| `Lesson` | владелец `content`; собственного `org_id` не имеет |
| `Module` → `Course` | путь от урока к организации |
| Блок | элемент страницы; для задания — только ссылка, не копия |
