# Contract: поверхность страницы курса

HTTP-договора у этой работы нет — ни одного нового эндпоинта. Договор здесь
другой: что страница обещает автору и на что опираются тесты.

## Строка урока

| Элемент | Роль | Обещание |
|---|---|---|
| Кнопка раскрытия | `button`, `aria-expanded`, `aria-controls` | переключает список, никуда не уводит |
| Название урока | ссылка на редактор урока | открывает редактор, как раньше |
| Кнопка «Edit» | ссылка на редактор урока | остаётся видимой |
| Сводка | текст | этой работой не меняется |

Клавиатура: Tab доходит до кнопки раскрытия, Enter и Space раскрывают, Escape
на раскрытом списке сворачивает и возвращает фокус на кнопку.

## Раскрытый список

```
Страница 1                         ← заголовок, только если страниц больше одной
  ▸ Что такое цикл                 ← текст, имя выведено
  ▸ Reading a range                ← задание, своё имя
  ▸ Сдать отчёт по лабораторной    ← работа, своё имя
  + Задание                        ← добавление на эту страницу
Страница 2
  ▸ …
  + Задание
```

Обещания:

1. Порядок элементов совпадает с порядком, в котором их видит ученик.
2. У каждого элемента есть имя. Выведенное имя визуально отличается от своего.
3. Ссылка элемента открывается в новой вкладке (`target="_blank"`,
   `rel="noopener"`), страница курса остаётся раскрытой.
4. Пустой урок показывает одну строку «содержимого нет» и добавление.

## Запросы при раскрытии

| Действие | Что уходит |
|---|---|
| Первое раскрытие урока | один `GET /exercises/by-lesson/{lessonId}`, плюс по одному `GET /assignments/{id}` на каждую встреченную работу |
| Повторное раскрытие того же урока | ничего: ответ уже в кэше |
| Раскрытие соседнего урока | только запросы этого урока |
| Загрузка страницы курса | ничего сверх сегодняшнего |

Последняя строка проверяемая: рендер-тест считает вызовы до раскрытия и после.

## Добавление задания

| Шаг | Обещание |
|---|---|
| Открытие меню | 26 типов, сгруппированы (basic, languages, math, programming, scorm), поиск по названию |
| Выбор типа | задание создаётся и встаёт последним на **этой** странице урока |
| После создания | список обновлён, новый элемент виден, ссылка ведёт на его страницу правки |
| Ошибка | список не меняется, сообщение видно, повтор возможен |

Место для второго пункта — «вставить существующее задание» — предусмотрено в
меню и появится вместе с `specs/030`.

## Ссылка с якорем

`/admin/lessons/{lessonId}/edit?courseId={courseId}&moduleId={moduleId}&block={blockId}`

Редактор урока обещает: после загрузки содержимого блок с этим идентификатором
видно без прокрутки, он подсвечен, подсветка снимается по первому действию.
Неизвестный идентификатор блока ничего не ломает — редактор открывается как
обычно.
