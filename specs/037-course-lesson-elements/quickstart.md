# Quickstart: как убедиться, что работа сделана

## Что нужно

- Ветка `feat/course-lesson-elements`, зависимости фронтенда установлены
  (`npm install` под Node 22).
- Учётная запись учителя или админа и курс, где есть урок с текстом и
  заданиями, а также урок из двух страниц.

## Тесты

```bash
cd frontend && npx vitest run src/app/\(admin\)/admin/courses src/lib/lessons
```

Ожидается: тесты сборки списка, вывода имён, адресов ссылок и рендера
раскрытия — зелёные. Каждый из них до правки падает: ни функций, ни панели не
существует.

```bash
cd frontend && npx tsc --noEmit
```

Ожидается: пусто.

## Проверка руками

Открыть `/admin/courses/{courseId}/edit`.

| Шаг | Ожидается |
|---|---|
| Раскрыть урок с текстом и тремя заданиями | четыре строки с именами в порядке урока |
| Раскрыть урок из двух страниц | заголовки страниц, элементы под своими |
| Раскрыть пустой урок | строка «содержимого нет» и добавление |
| Нажать на задание | новая вкладка со страницей этого задания |
| Нажать на текстовый блок | новая вкладка с редактором урока, блок видно без прокрутки и он подсвечен |
| Вернуться на вкладку курса | урок по-прежнему раскрыт |
| Добавить задание на второй странице | задание появилось последним на второй странице |
| Нажать на строку урока | открылся редактор урока |
| Свернуть и раскрыть тот же урок снова | запросов в сети нет |

## Что смотреть в сети

Открыть панель сети до раскрытия:

- при загрузке страницы курса — ни одного запроса за заданиями;
- при первом раскрытии — один `exercises/by-lesson/{lessonId}` и по одному
  `assignments/{id}` на каждую работу в этом уроке;
- при повторном раскрытии — ничего.

## Клавиатура

Пройти Tab до кнопки раскрытия, раскрыть Enter, пройти по элементам, свернуть
Escape. Фокус возвращается на кнопку раскрытия, кольцо фокуса видно на каждом
шаге.
