# Data Model: состав урока на странице курса

Хранилище не меняется. Здесь описано то, что собирается в памяти страницы из
уже приходящих данных.

## Источники

| Что | Откуда | Когда |
|---|---|---|
| Страницы и блоки урока | поле `content` урока, пришедшее вместе с курсом | сразу, без запроса |
| Названия заданий | `GET /exercises/by-lesson/{lessonId}` | при раскрытии урока |
| Названия работ | `GET /assignments/{assignmentId}` по встреченным идентификаторам | при раскрытии урока |

## Блок урока (существующее, для справки)

```
id            строка, вида block_<ts>_<rand>
type          text | html | video | presentation | exercise | assignment
sort_order    число, порядок внутри страницы
page          число, номер страницы
body?         строка или объект — содержимое текста и html
url?          строка — видео и презентация
exercise_id?  ссылка на задание
assignment_id ссылка на работу
```

Своего названия у блока нет — отсюда всё, что ниже.

## Элемент списка (новое, только в памяти)

```
blockId       строка       — тот же id блока, он же якорь ссылки
type          вид блока    — из блока
name          строка       — см. «Как получается имя»
nameKind      own | derived | pending | missing
href          строка       — куда ведёт ссылка правки
exerciseId?   строка
assignmentId? строка
```

`nameKind` существует ради интерфейса и тестов: выведенное имя показывается
приглушённо, `pending` — заглушкой нужной высоты, `missing` — как «задание не
найдено».

### Как получается имя

| Вид блока | Имя | Вид |
|---|---|---|
| `exercise` | название задания из запроса | `own` |
| `exercise`, ответ ещё не пришёл | тип задания | `pending` |
| `exercise`, задания нет в ответе | «задание не найдено» | `missing` |
| `assignment` | название работы из запроса | `own` / `pending` / `missing` |
| `text`, `html` | первые слова содержимого без разметки, до 60 знаков | `derived` |
| `text`, `html` пустые | «текст без содержимого» | `derived` |
| `video`, `presentation` | последняя часть ссылки без расширения | `derived` |
| `video`, `presentation` без ссылки | «видео без ссылки» | `derived` |

Обрезка по 60 знакам — по границе слова, с многоточием.

### Куда ведёт ссылка

| Вид блока | Адрес |
|---|---|
| `exercise` | `/admin/content-library/{exerciseId}` |
| `assignment` | `/admin/assignments/{assignmentId}` |
| остальные | `/admin/lessons/{lessonId}/edit?courseId=…&moduleId=…&block={blockId}` |
| `exercise` без задания | как у остальных — в редактор урока |

Все ссылки открываются в новой вкладке.

## Страница списка

```
index     число  — номер страницы урока, с нуля
elements  список элементов в порядке sort_order
```

Заголовок страницы показывается, только если страниц больше одной. Урок без
страниц (старый формат) даёт одну страницу со всеми блоками — так же, как его
видит редактор урока.

## Что кладётся при добавлении задания

```
задание:  { lesson_id, exercise_type, title: "New <Label>", config: {} }
блок:     { id, type: "exercise", exercise_id, page: <номер страницы>,
            sort_order: <последний на странице + 1> }
```

Урок после вставки сохраняется целиком: содержимое собирается обратно тем же
`buildPagesContent`, которым его собирает редактор урока.
