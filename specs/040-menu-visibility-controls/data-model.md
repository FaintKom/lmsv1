# Data Model: Six menu items a school cannot switch off

**Date**: 2026-08-22 · **Spec**: [spec.md](./spec.md) · **Research**: [research.md](./research.md)

**Ни схемы, ни миграций.** Карта видимости живёт в `Organization.settings` —
колонке `JSONB`. Меняется состав ключей, которые туда кладёт форма, и ничего
больше.

---

## Список того, что школа вправе скрыть

Новый модуль — единственное место, где этот список задан. Сегодня он задан
дважды и разошёлся на шесть строк.

| Поле | Что это | Пример |
|---|---|---|
| `key` | ключ в карте видимости | `peer_review` |
| `labelKey` | строка перевода **из меню**, не своя | `nav.peerReview` |
| `group` | категория, та же, что в меню | `learning` |
| `adminOnly` | пункт виден только администратору | `false` |

Порядок объявления — порядок показа в форме. Он совпадает с порядком в меню,
потому что берётся оттуда же.

### Чего в списке нет и почему

`dashboard`, `achievements`, `attendance`, `schedule`, `waitlist`,
`organizations`, `integrations` — у них нет ключа видимости. Школа не может их
скрыть, и эта работа этого не меняет (FR-014). Вопрос, вправе ли она, вынесен из
объёма.

## Карта видимости в настройках школы

```json
{
  "menu_visibility": {
    "courses": true,
    "journal": false,
    "gradebook": false
  }
}
```

**Отсутствующий ключ означает «показывать».** Это правило уже действует и делает
FR-006 бесплатным: школа, чья карта содержит десять ключей, получает шесть новых
включёнными, ничего не сохраняя.

### Что меняется в том, что сохраняет форма

| | до | после |
|---|---|---|
| Ключей в сохраняемой карте | 10 | 16 |
| Значения десяти прежних | из формы | **из формы, без изменений** |
| Значения шести новых | отсутствовали | `true`, пока школа не выключит |

**Опасное место.** Форма отправляет карту целиком, заменяя сохранённую. Если
собрать её со всеми шестнадцатью включёнными по умолчанию, первое же сохранение
включит обратно то, что школа выключала. Загруженные значения обязаны попасть в
карту до отправки — это FR-005 и FR-007, и они красные против наивной правки.

## Категории

Существуют, ничего не добавляется. Ключи заголовков — `nav.group.learning`,
`.people`, `.sessions`, `.progress`, `.school`, в этом порядке.

## Строки перевода

| | было | стало |
|---|---|---|
| Подписи пунктов | `admin.settings.menuUsers` и ещё девять | `nav.*`, те же, что в меню |
| Предупреждение о поддержке | нет | один новый ключ, шесть локалей |

Десять ключей `admin.settings.menu*` удаляются из шести локалей: их не читает
никто, кроме формы. Одна строка на пункт — расходиться нечему.
