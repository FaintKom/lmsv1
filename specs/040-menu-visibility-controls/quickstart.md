# Quickstart: Menu visibility controls

**Date**: 2026-08-22 · **Spec**: [spec.md](./spec.md) · **Contracts**: [contracts/ui.md](./contracts/ui.md)

Как убедиться, что работа сделана. Каждый сценарий начинается с того, что
показывает поведение **до** правки — принцип II: проверка, которая не может
упасть, хуже отсутствующей.

## Подготовка

```bash
docker compose -f docker-compose.qa.yml up -d --build --wait
```

Учётные данные QA лежат в репозитории намеренно и никогда не совпадают с продом.

```bash

```


## 1. Шестнадцать переключателей вместо десяти (US1)

**Красное до правки:** сегодня их десять.

1. Войти администратором, открыть `/admin/settings`.
2. Досчитать переключатели в разделе видимости меню.

**Ожидается:** шестнадцать. Среди них — библиотека материалов, взаимные
проверки, командные проекты, журнал, поддержка, заявки.

3. Выключить «Журнал», сохранить, перезагрузить.

**Ожидается:** пункта нет в меню; переключатель остался выключенным.

4. Включить обратно.

**Ожидается:** пункт вернулся.

## 2. Ученик тоже перестаёт его видеть (US5)

**Красное до правки:** сегодня ученик видит всё. `visible()` в его ветке не
вызывается ни разу — это и есть главная находка разбора.

1. Администратором выключить «Командные проекты», сохранить.
2. Войти учеником.

**Ожидается:** пункта в меню нет.

3. Открыть адрес этой страницы напрямую.

**Ожидается:** страница открывается. Выключен пункт меню, а не доступ — права не
участвуют.

## 3. Прежние решения школы не тронуты (US2)

Самая незаметная проверка и самая важная.

1. Взять школу, у которой в карте десять ключей и два из них выключены.
2. Открыть форму.

**Ожидается:** ровно эти два выключены; шесть новых включены.

3. Сохранить, **не тронув ни одного переключателя**.
4. Прочитать карту школы.

**Ожидается:** те же два выключены. Наивная правка, собирающая карту «все
включены», включит их обратно молча — именно это здесь и ловится.

## 4. Порядок и группировка (US3)

1. Открыть форму и выписать заголовки групп сверху вниз.
2. Открыть меню и выписать заголовки категорий.

**Ожидается:** совпадают и по составу, и по порядку.

3. Сверить подпись любого переключателя с подписью того же пункта в меню.

**Ожидается:** совпадают дословно — это одна и та же строка перевода.

4. Найти «Заявки», «Ученики», «Траектории».

**Ожидается:** у каждого пометка «только администратор».

## 5. Поддержка выключается с открытыми глазами (US4)

1. Выключить «Поддержку».

**Ожидается:** под переключателем появилось объяснение — ученик останется без
способа попросить помощи изнутри продукта.

2. Сохранить.

**Ожидается:** сохранение прошло. Предупреждение не блокирует.

3. Включить обратно.

**Ожидается:** объяснение исчезло.

## Проверка, ради которой всё это

**Б из [contracts/ui.md](./contracts/ui.md) §3.** Выключить все ключи списка и
посмотреть, что осталось.

**Ожидается:** ровно пункты без ключа — сводка, лист ожидания, организации,
интеграции. **Сегодня останутся ещё шесть**, и это ровно та проверка, которой не
хватало: разрыв существовал месяцами и не был виден ни одному тесту.

Выполняется для каждой роли со своим меню, включая ученика.

## Школа, которая ничего не выключала

Прогнать существующий обход тёмной темы и снимки экранов на организации, где
карта пуста.

**Ожидается:** ни одного отличия от нынешнего продукта, ни в одной роли. Самая
скучная проверка здесь и единственная, которая ловит случай «карта применилась
там, где школа ничего не просила».

## Мера предосторожности при проверке в браузере

Первой строкой любой проверки — `document.visibilityState`. В фоновой вкладке
Chrome не выдаёт кадров, и всё, что живёт на кадрах, замирает и читается как
поломка. Ошибка уже стоила ложного диагноза по проду 2026-08-21.
