# 066 — ещё четыре экрана, где отказ выдан за данные

specs/051 завела приём: сервер отказал — страница говорит об этом словами и не
предлагает того, что запрещено. Приём применили к `/admin/users`. Мобильный
обход (specs/065) прошёл те же страницы другими ролями и нашёл ещё четыре места
с той же болезнью.

## Что видно сейчас

| Страница | Кто | Сервер | Экран |
|---|---|---|---|
| `/admin/waitlist` | администратор | 403, список только для супер-администратора | «0 записей · Никто ещё не записался» |
| `/admin/org-members` | учитель | 403 | Форма добавления участника и «Участников (0) · Пока никого» |
| `/admin/crm` | учитель | 403 | «Не удалось загрузить» и тут же четыре пустые колонки воронки |
| `/admin/analytics` | учитель | 403 на девяти запросах | «Request failed with status code 403» в виджетах и вечное «Loading KPIs…» |

Первые два глотают отказ в `catch { toast.error(...) }`: сообщение живёт четыре
секунды, пустой список остаётся навсегда. Третий пишет об ошибке и всё равно
рисует доску, которой нет. Четвёртый показывает текст исключения из axios —
техническую строку, которую нельзя ни понять, ни исправить.

Все четыре достижимы только по прямой ссылке: меню этим ролям их не предлагает.
Это уменьшает частоту, но не делает экран честным.

## Заодно: виджет, который не умеет показать ошибку

```tsx
if (isLoading || !data) return <div>Loading KPIs…</div>;
if (error) return <div>{(error as Error).message}</div>;
```

При ошибке `data` не приходит, поэтому первая ветка забирает управление и вторая
недостижима: виджет показывает «Loading KPIs…» вечно — не только при отказе, а
при любом сбое запроса и любой роли. Порядок проверок надо поменять местами.

## Решение

Один общий компонент отказа вместо четырёх копий разметки: заголовок и фраза о
том, чьё это и к кому идти. Никаких кнопок действия — предлагать то, что сервер
запретит, и есть исходная ошибка.

- `waitlist`, `org-members`, `crm` — ловим 403 отдельно от прочих ошибок и
  показываем отказ вместо пустого состояния. Остальные ошибки ведут себя как
  раньше.
- `analytics` — страница закрыта тем же признаком, что и меню, поэтому отказ
  показывается сразу, а не после девяти неудачных запросов.
- Виджеты — порядок проверок исправлен, сырой текст исключения заменён
  человеческой строкой.

## Границы

`/admin/users` не трогаем: приём там уже работает, а файл сейчас в другом PR.
Перевести его на общий компонент — отдельная мелкая уборка.

## Проверка

Тест на каждую страницу: роль, которой отказано, видит объяснение и не видит
кнопки действия; роль, которой можно, видит данные. Проверка «отказ показан»
без второй половины зеленеет и на сломанной странице.
