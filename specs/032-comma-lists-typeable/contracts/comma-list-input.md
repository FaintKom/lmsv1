# Договор: поле списка через запятую

Внутренний договор между полем и четырьмя местами, которые его зовут.
Наружу, за пределы браузера, ничего не выходит.

## Что принимает

| Имя | Тип | Значение |
|---|---|---|
| `value` | `string[]` | список, каким его держит задание |
| `onChange` | `(next: string[]) => void` | вызывается на каждое изменение текста, получает разобранный список |
| `placeholderKey` | `string` | ключ перевода для подсказки |
| `className` | `string` | оформление места вызова; поле своего не навязывает |

Ключ, а не готовая строка: подсказка — текст для человека, и у неё есть
шесть переводов.

## Что обещает

1. Показывает то, что набрал учитель, пока набранное означает `value`.
2. Отдаёт в `onChange` список без пустых элементов и без пробелов по краям.
3. Пересобирает показанное из `value` только когда `value` означает не то,
   что показано, — то есть когда список пришёл извне.
4. Не переставляет и не переформатирует текст под курсором.

## Что не обещает

- Не проверяет содержимое: имя переменной и расширение файла — не его дело.
- Не запрещает дубликаты.
- Не хранит ничего между размонтированиями: задание — источник правды.

## Разбор и сравнение

```
parseList(text)   = text.split(",") → trim → выбросить пустые
sameList(a, b)    = одинаковая длина и поэлементное равенство
```

Обе — чистые функции в соседнем `.ts`, проверяются без отрисовки.
