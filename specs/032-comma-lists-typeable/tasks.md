# Tasks: Список через запятую можно набрать с клавиатуры

**Input**: Design documents from `/specs/032-comma-lists-typeable/`

**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md), [research.md](research.md), [contracts/](contracts/)

**Tests**: обязательны и идут первыми. Принцип II конституции: тест,
неспособный упасть, хуже отсутствия теста. Строку падения на сегодняшнем
коде приложить к PR.

**Organization**: четыре истории спеки — это четыре поведения одного поля.
Разделять их по разным реализациям нечего и не нужно: смысл правки в том,
что поведение одно на четыре места. Поэтому поле и его чистые функции стоят
в фундаменте, а фазы историй проверяют каждая своё.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: можно делать параллельно (разные файлы, нет незакрытых зависимостей)
- **[Story]**: US1–US4 из spec.md

## Path Conventions

Правка целиком в `frontend/src/`. Бэкенда, миграций и изменений схемы нет.

## Implementation Strategy

### MVP

Phases 1–3: поле, чистые функции и первое место вызова. Этого уже достаточно,
чтобы система уравнений перестала калечить переменные — самый тяжёлый из
четырёх случаев.

### Дальше

Phases 4–6 добавляют проверки поведения, не трогая код. Phase 7 переводит
остальные три места. Ни один шаг не ломает предыдущий.
