# Implementation Plan: Список через запятую можно набрать с клавиатуры

**Branch**: `fix/comma-lists-typeable` | **Date**: 2026-08-20 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/032-comma-lists-typeable/spec.md`

## Summary

Поле показывает не набранный текст, а результат его разбора. Правка меняет
это на противоположное: на экране остаётся то, что набрал учитель, наверх
уходит разобранный список.

Ключ — показывать текст, пока он **означает** пришедший список, и
пересобирать его из списка только когда список пришёл другой. Тогда `x,`
в середине набора остаётся на экране: родитель вернёт `["x"]`, а `x,`
означает ровно `["x"]`.

Одно поле ввода на все четыре места. Ни эффекта, ни второго состояния,
ни записи состояния во время отрисовки.

## Phase 0 — что выяснено

Подробности в [research.md](research.md). Коротко:

1. **Хук не годится.** Поле «ещё принимаются» отрисовывается внутри
   `questions.map(...)` (`exercise-config-editors.tsx:734`). Хук в теле
   `map` нарушает правила хуков. Значит компонент.
2. **Эффект не нужен и вреден.** `useEffect` на входящий список закрутит
   цикл: родитель отдаёт новый массив на каждое нажатие.
3. **Второе состояние не нужно.** Показываемый текст выводится: если
   разбор текста равен пришедшему списку — показываем текст, иначе
   собираем из списка. Чистая производная, без записи состояния во время
   отрисовки.
4. **Курсор не поедет.** Контролируемое поле двигает курсор, когда меняется
   `value`. Здесь `value` меняется только при смене смысла — то есть когда
   задание открыли заново.

## Phase 1 — устройство

### Поле

`CommaListInput` принимает список и отдаёт список. Договор — в
[contracts/comma-list-input.md](contracts/comma-list-input.md).

Внутри: одно состояние с набранным текстом, две чистые функции
(`parseList`, `sameList`) и вывод показываемого значения. Разбор и сравнение
живут в соседнем `.ts` — их проверяют без отрисовки.

### i18n

У поля нет своего текста, но храповик судит по файлу, а не по строкам.
Поле честно зовёт `useTranslation()` и берёт подсказку по ключу: сегодня
все четыре подсказки — английские литералы в файлах, которые храповик уже
пропустил («x, y», «.pdf, .png, .jpg», «Also accepted (comma-separated
variants)»). Три новых ключа в шести локалях закрывают и храповик,
и непереведённые подсказки.

Заносить файл в allowlist нельзя: allowlist разрешено только сокращать.

### Порядок

1. Красный тест: набор по символу, правка в середине строки, промежуточный
   `x,`, вставка из буфера, внешняя смена списка.
2. `comma-list.ts` — `parseList`, `sameList`.
3. `comma-list-input.tsx` — поле.
4. Четыре места вызова, старые обработчики удаляются.
5. Ключи в шести локалях.
6. Зелёный прогон, `tsc`, браузер на QA-стенде.
7. PR.
