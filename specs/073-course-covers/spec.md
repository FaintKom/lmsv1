# Feature Specification: обложки курсов, которые рисует код

**Feature Branch**: `feat/course-covers`
**Created**: 2026-10-02
**Status**: Направление выбрано: «Линии»

**Input**: «сделай картинки для всех курсов в минималистичном премиум стиле».
Владелец выбрал вариант A (обложки рисует код, база не трогается) и мотив
«Линии» из прототипа `prototype/covers.html`.

## Откуда задача

Курс без своей картинки (`thumbnail_url`) показывает цветное поле предмета с
названием (specs/071, направление C). Поле чистое, и рядом с курсами, у которых
картинка есть, выглядит недоделанным. Картинки для каждого курса — это запись в
базу прода и та же проблема у каждого нового курса. Рисунок, который строит
интерфейс, получает любой курс сразу.

## Requirements

- **FR-001**: Курс без своей картинки показывает на поле предмета тонкий
  линейный рисунок этого предмета: языки — реплики диалога со строками,
  математика — сетка с графиком функции, программирование — фигурные скобки и
  строки кода с отступами, остальное — концентрические дуги.
- **FR-002**: Рисунок зависит от id курса: тот же курс всегда выглядит так же,
  а соседние курсы одного предмета отличаются (свой график, свои отступы,
  своё число строк).
- **FR-003**: Рисунок стоит справа и не заходит под название. Курс со своей
  картинкой показывает её, как раньше.
- **FR-004**: Цвет линий — токены `--subject-line-*`, свои в каждой теме.
  Рисунок декоративный: скрыт от экранного диктора и не ловит клики.
- **FR-005**: Где: карточка каталога, карточка курса в админке, шапка
  страницы курса, блок «продолжить» на главной ученика. В шапке и в блоке
  на телефоне рисунка нет — там под ним оказался бы текст.

Вне задачи: выбор материала на живом уроке (плашка 56px), загрузка своих
картинок, отдельная колонка «предмет» у курса.

## Решение

`frontend/src/lib/course-cover.ts`: `coverArt(subject, seed)` возвращает
разметку SVG (viewBox 320×144), `coverArtProps` — готовые атрибуты `<svg>`.
Генератор псевдослучайных чисел посеян id курса. Разметка собирается только из
чисел, посчитанных кодом, — пользовательского текста в ней нет.

## Success Criteria

- **SC-001**: Каждый курс без картинки в каталоге показывает рисунок своего
  предмета; два курса одного предмета не совпадают.
- **SC-002**: Название курса читается целиком: рисунок под него не заходит
  ни на десктопе, ни на 320px.
- **SC-003**: Страж дизайн-системы и `course-cover.test.ts` зелёные.
